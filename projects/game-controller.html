Video Game Controller Enhancements

Overview

This project involved designing and implementing a wireless ESP32-based game controller for a modified version of the classic Space Invaders game. The controller communicated with the game via sockets and Bluetooth, enabling real-time movement, firing, haptic feedback, and visual indicators. The goal was to redesign the controller to be more intuitive, more responsive, and more feature-rich by implementing three major improvements and adding three new hardware-driven features.

Key Improvements Implemented

1. Improved Movement Responsiveness

  • Calibrated the accelerometer using empirically derived thresholds, enabling four sensitivity levels tied to X-axis acceleration.
  • Rewrote movement logic to isolate X-axis data and remove interference from Y/Z axes.
  • Enhanced smoothness and precision by mapping tilt angle to proportional movement speed.

2. Decoupled Movement and Firing Actions

  • Refactored command parsing in the game code:
    • Original version only allowed one command per frame.
    • Updated to detect multiple simultaneous actions by checking for command substrings instead of full-string matches.
  • Result: Player can fire while moving, drastically improving playability.

3. Added Photodetector-Based Firing

  • Replaced forward-tilt firing with a more intuitive photodetector “touch-to-fire” mechanism.
  • When the PPG sensor reading rises above a threshold, the controller sends continuous "FIRE" commands.
  • Improved firing precision and removed conflicts with movement.

New Features Added

1. Haptic Feedback When Shot

  • Implemented buzz motor activation when the player is hit:
  • Adds an immersive tactile feedback layer for gameplay.

2. Life Counter With LED Indicators

  • Added a three-LED system (green → yellow → red) to visually display remaining lives on the controller.
  • Automatically resets LEDs when the game restarts.

3. OLED Display for Score and Lives

  • Added an on-device scoreboard that updates in real time.
  • ESP32 stores and displays: Current score and Remaining lives (synced with LED system)

Technologies Used

Software: Python (Pygame) • Socket Programming • Arduino (C++) • Bluetooth

Hardware: ESP32 • OLED Display • 3-axis Accelerometer • Photodetector • Vibration Motor • LEDs
